# Componentes de terceros

La presentación incluye liquid-glass-react 1.1.1, de rdev: https://github.com/rdev/liquid-glass-react, licencia MIT. Se usa para la navegación flotante. Python conserva las reglas de negocio y las estructuras académicas; este componente no sustituye ninguna de ellas.

React, Vite, lucide-react y pywebview se mantienen como dependencias declaradas. Sus licencias permanecen en los paquetes distribuidos; conservarlas cuando se empaquete el ejecutable.
