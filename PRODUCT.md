# Producto

Nombre: Sistema de Gestión de Reservas de Hotel.
Usuario: recepcionista de un hotel pequeño, una computadora y un operador.
Tareas: registrar huéspedes y habitaciones; comprobar disponibilidad; reservar; check-in y check-out; cobrar; gestionar espera FIFO; revisar reportes e historial.
Objetivo académico: Python con nodos, listas, cola, árbol binario de búsqueda, recursión, Merge Sort, excepciones y archivos.
Interfaz aprobada: React, ventana de escritorio, estilo macOS y Linear, pocos paneles; empaquetado Windows al final del proyecto.
Fuera de alcance: facturación fiscal, reembolsos, múltiples recepcionistas simultáneos, servicio web público.
